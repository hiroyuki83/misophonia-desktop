# Misophonia Desktop / ミソフォニア向け音フィルター

ユーザーが苦手な音の**短い録音サンプルを登録**し、音声ファイルから似たスペクトルの音を減衰する、Windows向け無料・ローカル実行の試作アプリです。

> **現在は研究・評価向けMVPです。** 登録音を認識して完全に分離するAIモデルではありません。単純な反復音や特徴的な音では改善することがありますが、会話に混ざる咀嚼音・口の音などの確実な除去はできません。音の誤除去、音質劣化、聞き落としがあります。警報音など重要音の判別を保証しません。

## 無料で使える範囲

- 有料API、クラウド推論、サブスクリプション、ログイン、音声アップロードは不要。
- Python標準GUI（Tkinter）と、ローカルのNumPy / SciPy / SoundFile / sounddeviceで動作。
- 登録サンプルは自分のPCの `%LOCALAPPDATA%\MisophoniaDesktop\samples` に保存。
- 入力と出力はWAVファイルを推奨。現段階は**録音済みファイルの処理**であり、PC/マイク音声のリアルタイム抑制、外音キャンセリング、ヘッドホンANCは未実装。
- 使用するライブラリは無償で利用可能。Pythonや依存ライブラリの配布条件は各ライセンスを参照してください。

## Windowsで起動

1. [Python 3.11以上](https://www.python.org/downloads/windows/) をインストール（Tkinterを含む通常のWindows版）。
2. リポジトリをGitHub Desktopでクローン。
3. `start.bat` をダブルクリック。初回のみネット接続を使って無料ライブラリをインストール。
4. 「音を登録」で、比較的クリアに録れたトリガー音のWAVを追加する（「4秒録音」も利用可能）。
5. 一覧から除去したい音を選び、処理対象WAVと出力先を指定。
6. 「ファイルを処理」を押し、元ファイルと聴き比べて調整する。

コマンドラインからも起動できます：

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

## パラメータ

- **減衰の強さ**：対象だと判断された周波数帯をどれくらい弱めるか（0～100%）。
- **判定の厳しさ**：大きいほど誤除去が少なくなる傾向があり、検出漏れが増える可能性があります。小さいと逆の傾向があります。
- 登録音はできれば0.5～10秒程度、背景が静かな状態で録音してください。

## 処理原理と限界

登録したサンプルの短時間フーリエ変換（STFT）からスペクトルの特徴を抽出し、入力音声の各時間フレームとの類似度が閾値を超えた箇所に**ソフトな周波数マスク**を適用します。特定音の存在を確定するものでも、厳密な音源分離でもありません。音量・位置・背景音の違いに弱く、他の似た音も減衰します。

ファイルは最大120秒（プロトタイプのメモリ保護用）。録音・再生時は音量に注意し、危険を知らせる音が入る環境では使用しないでください。
